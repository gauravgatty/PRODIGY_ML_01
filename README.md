# 🏠 House Price Prediction Website

A Machine Learning web application that predicts house prices using Linear Regression.

---

## 🚀 Technologies Used

- Python
- Flask
- HTML
- CSS
- Scikit-learn
- Pandas
- NumPy

---

## 📌 Features

✅ Predicts house prices using Machine Learning  
✅ Modern responsive UI  
✅ Linear Regression model  
✅ INR currency prediction  
✅ Flask web integration  
✅ User-friendly interface  

---

## 🧠 Machine Learning Model

This project uses:

Linear Regression

to predict house prices based on:
- Square Feet
- Bedrooms
- Bathrooms

---

## ▶️ Run the Project

Install dependencies:

pip install flask pandas scikit-learn numpy joblib

Run application:

python app.py
